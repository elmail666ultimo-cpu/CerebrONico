QUÉ ARREGLA
-----------
El problema: subes una app que funciona, pides una mejora, y el modelo (Gemini
3.5 Flash, GLM 4.5…) reescribe de memoria un archivo que no leyó y te lo devuelve
mutilado. Eso PASABA porque el guardián de sintaxis no puede rechazar un archivo
mal equilibrado y perfectamente balanceado — y en .ts/.tsx no valida llaves a
propósito (falsos positivos con genéricos y JSX).

Qué hace ahora:
  · Juzga cada escritura ANTES de tocar el disco: bloquea si desaparecen
    exportaciones, si el archivo pierde ≥35 % de líneas útiles, si trae
    marcadores de truncado («…», «resto del código») o si el package.json pierde
    dependencias/scripts. Entre 12 % y 35 % avisa y deja pasar.
  · Guarda copia de cada archivo ANTES de tocarlo (.cn-quirofano/ultima.json),
    y si una tanda rompe algo, la REVIERTE y te cuenta por qué en el chat.
  · Mete el CONTRATO QUIRÚRGICO en el prompt de sistema, para que el modelo no
    lo intente siquiera.
  · Añade dos herramientas al modelo: `revisar_cambios` y `deshacer_cambios`,
    y tres endpoints para la IDE: /api/quirofano/estado · /revisar · /deshacer

CÓMO ARRANCARLO (esto es lo importante)
---------------------------------------
  A) Desarrollo (usa el código fuente parcheado)  →  ya funciona tal cual:
       cd ide\backend
       npm install
       npm run dev

  B) Producción / el EXE (usan el bundle ya compilado) → HAY QUE RECOMPILAR UNA VEZ:
       cd ide\backend
       npm run build      (genera dist\server.mjs CON el Quirófano dentro)
       npm start
     Si no haces `npm run build`, el EXE y `npm start` siguen corriendo el
     server.mjs viejo y el Quirófano NO actúa. Esto es lo único que hay que
     recordar.

PUERTAS PESADAS (opcionales, caras)
----------------------------------
  QUIROFANO_GATES=tipos,humo npm run dev
    tipos → npx tsc --noEmit, y sólo culpa de errores en archivos que la
            operación tocó (los errores viejos de otros sitios no cuentan)
    humo  → GET a la vista previa (:3500); un 500 o vacío revierte la tanda
  QUIROFANO_CIERRE_MS=6000   (cuánto espera sin escrituras para juzgar la tanda)
  QUIROFANO_SIN_IMPORTS=1    (desactiva la puerta de imports si te molesta)
